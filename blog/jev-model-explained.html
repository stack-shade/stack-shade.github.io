Jev Model Explained: AI Decision Models, Typed Outputs, Probabilities and Agents

Jev is TypeSafe AI's first public System One model, designed around typed probabilistic decisions for software.

The mental model: writer vs switchboard

A writer generates explanations; a switchboard routes decisions.

The three primitives

Choice selects an option. Score rates an input. Noul answers a yes/no-style question probabilistically.

AI agents

Agents repeatedly choose tools, inspect results, retry, escalate, continue or stop.

The bigger idea

LLMs generate. Jev decides. Code executes.
