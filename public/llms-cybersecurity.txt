## Learning contract

Practice only on systems you own or have explicit authorization to test. Define scope and stop conditions, preserve evidence before modifying state, validate findings, remediate, and retest.

## Capabilities

- Threat modeling and secure design
- Network, Linux, Windows and identity security
- Web/API security testing in controlled labs
- Vulnerability management and remediation
- SOC operations, SIEM and network telemetry
- Detection engineering and ATT&CK mapping
- Digital forensics and incident response
- Malware analysis and reverse engineering in isolated environments
- Cloud, containers and DevSecOps security
- AI security, RAG security and model supply-chain risk

## Lesson model

Every lesson is generated as a self-contained learning resource with an answer-first overview, mental model, analogy, deep dive, evidence-oriented flow, reconstruction artifact, misconceptions, active recall, Feynman teach-back and exam/interview angle.
