# NLP Curriculum Map

## Topic-to-skill map

### Foundations
Text normalization, tokenization, sentence segmentation, corpus preparation.

### Linguistics
Morphology, syntax, semantics, POS tagging, NER, dependency parsing, ambiguity.

### Classical
N-grams, smoothing, Naive Bayes, logistic regression, HMMs, Viterbi.

### Representation
Bag of Words, TF-IDF, similarity, embeddings, Word2Vec, negative sampling.

### Neural
Backpropagation, RNNs, LSTMs, GRUs, bidirectionality.

### Attention
Encoder-decoder, alignment, Q/K/V, scaled dot-product attention, cross-attention.

### Transformers
Position, multi-head attention, residuals, normalization, feed-forward blocks, masking.

### LLMs
Causal LM, masked LM, tokenizers, pretraining, decoding, fine-tuning, adapters.

### Systems
RAG, retrieval, reranking, tool use, structured output, agent loops.

### Evaluation
Precision, recall, F1, generation metrics, human evaluation, hallucination, bias, safety.

### Production
Data versioning, inference latency, batching, caching, drift, monitoring, multilingual and domain adaptation.

## Assessment ladder

Each topic should progress through:

**recognize → explain → calculate/trace → implement → debug → design**

The final capstone is a design-and-build task, not only a coding task.
