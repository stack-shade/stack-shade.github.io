ACTIVE RECALL
git reset --hard gone wrong — why is nothing ever lost?

reflog records every HEAD movement for ~90 days; find the pre-reset SHA and reset back to it.

Why never rebase shared/public branches?

Rebase rewrites commit hashes — teammates' clones diverge and every future merge duplicates/conflicts. Rebase local work only.
