ACTIVE RECALL
Why fetch data in Server Components when possible?

No client waterfalls, direct DB access, zero JS shipped for static parts — and secrets never reach the browser.

What can't a Server Component do?

Use state/effects/event handlers or browser APIs — it never hydrates. Interactivity must live in a Client Component leaf.
